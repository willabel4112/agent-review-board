# Publication notes

This package is an allowlisted export of the working application, followed by
portability edits. It starts a new public Git history.

Included: server, CLI, domain library, browser assets, event contract, service
templates, tests, new documentation and synthetic demonstration data.

Excluded: original Git history, production documents, original review events,
private notes, drafts, registries, snapshots, logs, session identifiers, machine
inventories and production screenshots. The historical regression fixture was
replaced with a newly written migration plan. Screenshots are taken from the
synthetic demo using a generic host alias.

The 0.2.0 update selectively ports the native Windows IO/process/service seams,
snapshot/resource path checks, and the batch confirmation repair. It preserves
the public English interface, `RB_DATA_DIR`, and portable agent identity.
Windows tests and installer fixtures are synthetic. Private authentication,
peer configuration, network setup, operational evidence and handoff files are
excluded. The earlier public SSH helper and peer directory have been removed.
No private inventory or ambient session-registry integration is required.

Historical accounts are paraphrased and counts generalized. They are operator
experience, not independently audited quantitative claims. The release's tests
make the mechanisms inspectable without disclosing the original work.
