# How should we choose the questions?

> Synthetic child document, attached to a question in the parent review.

Choose the question set before inspecting the candidate tools' results. Include
queries that are easy to state but difficult to retrieve, and some for which the
collection has no relevant document.

## A small reviewable matrix

| Question type | What it reveals |
|---|---|
| Exact name | Basic indexing and matching |
| Paraphrase | Retrieval beyond matching words |
| Ambiguous phrase | Whether the tool offers useful alternatives |
| Absent answer | Whether it admits the missing evidence |

The matrix helps structure an evaluation. It does not make a small sample
representative by itself. Keep the limitation next to the recommendation.

## Return to the main decision

Once the sampling rule is agreed, edit the parent's evaluation plan. The thread
keeps the reasoning; the parent contains the current decision.
